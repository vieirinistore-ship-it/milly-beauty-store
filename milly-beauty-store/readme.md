# Milly Beauty - Catálogo Online

Marketplace simples de produtos de estética com integração WhatsApp.

## 🚀 Hospedado no Vercel

## 📋 Como Fazer Deploy

### Pré-requisitos:
- Conta GitHub (gratuita em github.com)
- Conta Vercel (gratuita em vercel.com)

### Passo 1: Criar Repositório no GitHub

1. Acesse github.com e faça login
2. Clique em "+" (canto superior) → "New repository"
3. Nome: `milly-beauty-store`
4. Deixe público
5. Clique "Create repository"

### Passo 2: Upload dos Arquivos

1. Na página do repositório, clique "Add file" → "Upload files"
2. Arraste todos estes arquivos:
   - `index.html`
   - `app.js`
   - `data.js`
   - `styles.css`
   - `vercel.json`
   - Pasta `img/` com suas imagens

3. Escreva a mensagem: "Initial commit"
4. Clique "Commit changes"

### Passo 3: Deploy no Vercel

1. Acesse vercel.com e faça login com GitHub
2. Clique "Add New..." → "Project"
3. Selecione o repositório `milly-beauty-store`
4. Clique "Import"
5. Configure:
   - **Framework Preset**: Other
   - Build Command: deixe em branco
   - Output Directory: deixe em branco
6. Clique "Deploy"

**Pronto! Seu site estará online em segundos!** 🎉

### Passo 4: Usar seu próprio domínio (opcional)

1. No Vercel, vá para seu projeto
2. Clique "Settings" → "Domains"
3. Adicione seu domínio
4. Siga as instruções para apontamento DNS
